Your cases

CaseMap is a verbatim document-indexing assistant, not a legal-research or drafting tool: it turns a bundle of PDFs or Word filings into a page-and-paragraph-cited timeline, document breakdown, and citation list — every fact is a direct excerpt from the source, with an exact reference back to it. It doesn't summarize, paraphrase, generate, or reason about your case; it only finds and organizes what's already on the page.

Every case lives only in this browser — nothing is kept on the backend after processing. By default, the only thing that ever leaves this device is an anonymous page-load count (no document data, ever) so the people behind this tool know it's actually being used. Turning on "Look up cited provisions online" (off by default, on the upload screen) additionally sends each cited provision's own citation — never document content — to India Code (via eCourtsIndia's public API) to fetch its exact text.

⚠

Verify before relying on it. Extraction can miss or misread a fact — especially on poor-quality scans, non-English text, or unusual formatting — and it never checks whether a cited provision is still good law. Treat every date, amount, and citation as a first pass to confirm against the original document yourself, not a second opinion.
